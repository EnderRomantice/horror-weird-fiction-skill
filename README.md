# Horror Weird Fiction Skill

`horror-weird-fiction` 是一个用于生成怪异恐怖故事的写作 skill。

它聚焦于日常环境中的细微异常、规则失真、认知污染和渐进式不安，尽量避开鬼怪现身、血腥描写和传统惊吓桥段。

## Overview

这个 skill 的目标是让恐怖输出更稳定，避免文本被热闹情节带偏。

它默认强调以下几件事：

- 从普通、可观察的场景起步
- 用单一异常驱动整篇故事
- 通过重复、偏差和升级制造不安
- 用动作、感官和环境变化代替直接情绪描述
- 保持留白，不急于解释异常来源

## What It Is Good At

- 日常异化：熟悉事物每天偏离一点
- 规则扭曲：时间、空间、数字、秩序局部失真
- 认知污染：信息、记忆、观察行为本身开始扩散异常
- 存在怀疑：主角逐步失去对现实或自我的确定感
- 空间异常：门、走廊、房间、路径不再可靠

## What It Avoids

- 冤魂、鬼怪、血手印、古老诅咒之类现成元素
- jump scare 驱动的短促惊吓
- “都是梦”“精神问题”“恶作剧”式收尾
- 解释过满，把未知完全讲透

- `skills/SKILL.md`: 核心规则与默认输出方式
- `skills/references/weird-style.md`: 异常类型、推进节奏、修订要点

- `example/village-weird-tale.md`: 偏克制、偏冷感的示例

## Writing Model

这个 skill 默认采用一条比较稳定的写法：

1. 建立日常基准
2. 放入一个轻微异常
3. 让主角观察、记录、比对或测试
4. 让异常按同一方向升级 2 到 4 次
5. 用一个无法彻底解释的状态收尾

重点在于维持持续的不协调感，让异常慢慢积累。

## Usage Notes

- 写短篇时，最好只保留一个核心异常
- 写长篇时，先列出异常升级阶梯再展开正文
- 第一人称通常更容易维持压迫感和视角限制
- 如果要做反转，尽量只做一次，并确保前文已有线索

## Positioning

这个项目的定位更偏向“写作控制器”。

它提供的是输出约束、节奏框架和语言方向，目的是让模型更稳定地写出冷、缓、持续失衡的怪异恐怖文本。
